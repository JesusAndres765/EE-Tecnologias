# P03 - Ramas y Conflictos

## Propósito
Práctica enfocada en la creación de ramas, integración de código y resolución explícita de conflictos.

## Herramientas y Versiones
* **Lenguaje:** Java 11
* **Gestor de construcción:** Maven 3.x
* **Framework de Pruebas:** JUnit 5.9.2
* **Control de Versiones:** Git

## Guía Breve de Reproducción
Para verificar el funcionamiento y las pruebas de este proyecto, ejecuta los siguientes comandos desde la raíz del repositorio:

1. **Limpiar el entorno de construcción:**
   `mvn clean`
2. **Ejecutar la suite de pruebas unitarias:**
   `mvn test`
3. **Comprobar el historial y la resolución del conflicto:**
   `git log --all --decorate --oneline --graph`
